# Security

Reversal runs on your own computer. The command line converts the files you name, and the web
UI is a server on 127.0.0.1 that only its own page may call. There are no accounts, no network
services and no telemetry.

If you find a vulnerability, please report it privately through
[Report a vulnerability](https://github.com/janwiktor/reversal/security/advisories/new) rather
than in a public issue, so it can be fixed before it is announced.
